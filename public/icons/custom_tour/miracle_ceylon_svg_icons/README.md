# Miracle Ceylon Custom Tour SVG Icon Pack

Original Font Awesome-inspired outline icons for the Custom Tour page.
They use:
- `fill="none"`
- `stroke="currentColor"`
- `stroke-width="1.8"`
- `viewBox="0 0 24 24"`

## Astro usage

```astro
<img src="/icons/custom-tour/private-driver-guide.svg" alt="" class="h-6 w-6" />
```

Recommended better inline usage:

```astro
<span class="text-[var(--color-primary)]">
  <!-- paste SVG here or import as raw if your setup supports it -->
</span>
```

## Suggested folder

Copy all SVG files to:

`/public/icons/custom-tour/`
